# Astrelio

Frontend-only astrology app — natal charts, transits, secondary progressions, solar returns, and synastry. Vue 3 + Pug + Pinia + `astronomy-engine`. Bilingual (pt-BR / en). Deployed to GitHub Pages.

## Stack

- **Vue 3** with Composition API + `<template lang="pug">`
- **Vite 6** + **Tailwind v4**
- **Pinia** with `pinia-plugin-persistedstate` for the local archive
- **astronomy-engine** (MIT) for planet positions
- Custom port for **Placidus / Koch / Porphyry / Regiomontanus / Equal / Whole-Sign** house systems
- Offline city lookup generated from **GeoNames cities1000** coordinates and IANA timezones
- **`@astrodraw/astrochart`** for the SVG wheel
- **three.js** for the WebGL star background and the 3D planetarium
- **vue-i18n** with pt-BR / en JSON locales (pt-BR is source of truth)
- **vue-router** in hash mode (no GH Pages 404 redirects)
- **vite-plugin-pwa** for offline support
- **Vitest** for ephemeris/houses/aspects unit tests
- **Playwright** for end-to-end specs (Chromium + WebKit)

## Quick start

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run test       # Vitest
npm run e2e        # Playwright (auto-builds + serves preview)
npm run build      # production build to docs/
GITHUB_PAGES=1 npm run build   # build with /astrelio/ base path
npm run smoke:dev  # Vite dev-server smoke check for /#/human-design
npm run build:planet-maps   # refresh public/planets/maps textures (needs ImageMagick)
```

CI uses `npm ci`, so keep `package-lock.json` in sync with dependency changes. Restart `npm run dev` after installing dependencies so Vite does not hold stale module paths.

Static builds are emitted to `docs/` by default for GitHub Pages. Do not commit generated `dist/` output.

## Planetarium

`/planetarium/:view` is a full solar-system planetarium with four views, all driven by
`astronomy-engine` rather than canned data:

- **Orrery** — heliocentric, real elliptical orbits, compressed or true distance scale, with 20 major
  moons around whichever planet is focused
- **Sun · Earth · Moon** — why phases happen, with a from-Earth inset, the 5.1° tilted lunar orbit and its nodes
- **Eclipses** — past and upcoming eclipses with true-scale umbra/penumbra cones and a shadow diagram
- **Retrograde** — the apparent sky track of a planet with its stations, plus a heliocentric inset showing the overtaking

The event catalog covers eclipses, moon phases, supermoons, lunar nodes, seasons, apsides,
elongations, peak brightness, oppositions, conjunctions, retrograde stations, solar transits,
close pairings and occultations. It is computed in a Web Worker over the visible time window.

Moons: Io, Europa, Ganymede and Callisto are positioned from the ephemeris (`JupiterMoons`). The
other sixteen — Phobos, Deimos, the seven major Saturnian moons, the five Uranian moons, Triton and
Charon — are modelled from published mean elements, so their size, distance, period, inclination and
direction of travel are real while the phase along the orbit is approximate; the body panel says so.
All of them are tidally locked to their planet, and Triton comes out retrograde on its own.

Body textures are equirectangular maps under `public/planets/maps/`, generated by
`npm run build:planet-maps` (Solar System Scope, CC BY 4.0; NASA and USGS Astrogeology imagery,
public domain). Moons without a published global mosaic — Mimas, Deimos and the Uranian five — are
rendered as tinted spheres.

## Storage

- `astrelio_people`   — Pinia, persisted in localStorage. Person records: `{ id, name, isoLocal, ianaZone, tzOffsetMinutes, lat, lon, placeLabel, createdAt }`
- `astrelio_settings` — Pinia, persisted. `{ locale, houseSystem, zodiac, skyEnabled, theme }`
- `astrelio_planetarium` — Pinia, persisted. View, playback rate, scale and display preferences
- `astrelio_locale`   — mirrored standalone for first-paint locale detection
- session store        — in-memory only

## Deploy

Push to `main`. The workflow builds `docs/` with `GITHUB_PAGES=1` so Vite's `base` resolves to `/astrelio/`, then deploys via `actions/deploy-pages@v4`. Repo Settings → Pages → Source = "GitHub Actions".

Do not commit generated `dist/` output for deploys. Use `docs/` for committed static Pages artifacts.

For a custom domain, drop a `CNAME` file into `public/` and remove the `base` override in `vite.config.js`.
