# Planet surface maps

Equirectangular body maps used by the 3D planetarium. Generated by `npm run build:planet-maps`.
Solar System Scope textures are CC BY 4.0 (https://www.solarsystemscope.com/textures/);
NASA/New Horizons imagery is public domain.

## Moons

Global simple-cylindrical mosaics from USGS Astrogeology (public domain). Greyscale plates are
tinted by the renderer rather than recoloured here.

- io: Io_GalileoSSI-Voyager_Global_Mosaic_ClrMerge_1km.tif (public domain) — USGS/NASA Galileo SSI + Voyager colour merge
- europa: Europa_Voyager_GalileoSSI_global_mosaic_500m.tif (public domain) — USGS/NASA Voyager + Galileo SSI
- ganymede: Ganymede_Voyager_GalileoSSI_global_mosaic_1km.tif (public domain) — USGS/NASA Voyager + Galileo SSI
- callisto: Callisto_Voyager_GalileoSSI_global_mosaic_1km.tif (public domain) — USGS/NASA Voyager + Galileo SSI
- titan: Titan_ISS_P19658_Mosaic_Global_4km.tif (public domain) — USGS/NASA Cassini ISS
- enceladus: Enceladus_Cassini_mosaic_global_110m.tif (public domain) — USGS/NASA Cassini ISS
- rhea: Rhea_Cassini_Voyager_mosaic_global_417m.tif (public domain) — USGS/NASA Cassini + Voyager
- dione: Dione_Cassini_Voyager_mosaic_global_154m.tif (public domain) — USGS/NASA Cassini + Voyager
